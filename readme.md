# Gleam Connect

**A modern VPN client for Android.**

Gleam Connect is a VPN application designed for a simple, convenient, and reliable connection experience.

## Compatibility

Gleam Connect is designed exclusively for use with **Gleam VPN** configuration links.

The application only supports configuration links issued by Gleam VPN. Third-party VPN subscriptions and configuration links are not supported.

## Download

**[Download Gleam Connect for Android](https://github.com/gleamnetworks/gleam-connect/releases/latest)**

## Installation

1. Download the latest APK from GitHub Releases.
2. Open the downloaded APK on your Android device.
3. Allow installation from this source if Android requests permission.
4. Complete the installation and launch Gleam Connect.
